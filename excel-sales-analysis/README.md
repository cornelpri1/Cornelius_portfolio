# Sales Data Cleaning and Analysis Using Excel

## Project Overview
This project focuses on cleaning, organizing and analyzing a messy sales dataset using Microsoft Excel.

## Objectives
- Identify and correct data quality issues.
- Remove duplicate records.
- Standardize dates, names, cities and payment methods.
- Handle missing and inconsistent values.
- Analyze sales performance using PivotTables.
- Present findings through charts and visualizations.

## Tools Used
- Microsoft Excel
- PivotTables
- Excel Formulas
- Data Cleaning
- Data Visualization
